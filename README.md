# Cancionero en vivo

Cancionero para grupos de música católica: grupos, biblioteca de canciones con acordes, cancioneros con tono propio, salas en vivo sincronizadas por código, grabaciones y afinador.

- Página estática (GitHub Pages) + Supabase (registro, base de datos, tiempo real y archivos).
- `supabase/schema.sql`: estructura y permisos de la base.
